Garantía de Inspección Bidireccional en GCP

Model Armor Floor Settings inspecciona tanto el prompt de entrada (SANITIZE_USER_PROMPT) como la respuesta generada por el modelo (SANITIZE_MODEL_RESPONSE). Cuando el prompt es limpio pero la respuesta del modelo contiene PII (ej. tarjeta o SSN de un expediente) o un enlace malicioso, el modelo se ejecuta en Vertex AI Reasoning Engine y Model Armor intercepta la salida antes de entregarla al usuario.
